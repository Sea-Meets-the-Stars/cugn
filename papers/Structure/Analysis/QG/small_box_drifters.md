## Context

We wish to analyze the outputs of a quasigeostrophic model in a small box.  The box is a 100 km x 100 km domain near the center of the model domain with a 10 km x 10 km grid.  The model is run for 100 days.  The model output is saved in a NetCDF file.  We will use the Python interface to the Julia code to run the model.

## Here is how the activity should be organized

### QG output file

The QG output file is located at `$OS_DATA/QG/QGModelOutput20years.nc` (~23 GB). It was generated by [pyqg](https://pyqg.readthedocs.io/en/latest/index.html), a Python Quasigeostrophic Model.

**Grid:** 256 x 256 cells on a 1000 km x 1000 km doubly-periodic domain (grid spacing ~3.9 km).

**Layers:** 2 vertical levels (`lev` = 1, 2) with a layer interface at `lev_mid` = 1.5. Layer thickness ratio `delta` = 0.25 (upper layer is 1/4 of total depth).

**Time:** 7200 daily snapshots (~19.7 years). Model timestep `dt` = 3600 s (1 hour); output written every day.

**Variables:**
| Variable | Dimensions | Units | Description |
|----------|-----------|-------|-------------|
| `q` | (time, lev, y, x) | s^-1 | Potential vorticity in real space |
| `u` | (time, lev, y, x) | m s^-1 | Zonal velocity anomaly |
| `v` | (time, lev, y, x) | m s^-1 | Meridional velocity anomaly |

**Spectral coordinates:** `k` (129 zonal wavenumbers) and `l` (256 meridional wavenumbers) for Fourier-space analysis.

**Key physical parameters:**
- `beta` = 1.5e-11 m^-1 s^-1 (planetary vorticity gradient)
- `rd` = 15 km (Rossby deformation radius)
- `rek` = 5.787e-7 s^-1 (bottom friction)
- `del2` = 0.8 (Laplacian diffusion coefficient)

# Requirements

## R1: Modify Julia `deploy_drifters()` in `jl/qg_drifters.jl`

Add optional keyword arguments to `deploy_drifters()` to support box deployment:

```julia
deploy_drifters(n_per_side::Int, nx::Int;
    box_center_x::Float64=NaN,   # grid-index x-center (NaN = full domain)
    box_center_y::Float64=NaN,   # grid-index y-center
    box_size_km::Float64=NaN,    # box side length in km
    drifter_spacing_km::Float64=NaN,  # spacing between drifters in km
    dx::Float64=3906.25)         # grid spacing in meters
```

**Behavior:**
- If `box_size_km` is NaN (default), fall back to the existing full-domain deployment (backward compatible).
- If `box_size_km` is specified, ignore `n_per_side` and compute the grid from box parameters:
  - `n_per_side_box = floor(box_size_km * 1000 / (drifter_spacing_km * 1000)) + 1`
  - Positions centered at `(box_center_x, box_center_y)` in grid-index units.
  - Default center: `(nx/2, nx/2)`.
  - Default spacing: 10 km.

## R2: Modify Julia `run_drifters()` in `jl/qg_drifters.jl`

Pass the new box parameters through to `deploy_drifters()`. Add keyword arguments:

## R5: Create Python module `py/small_box_drifters.py`

A thin wrapper around `qg_drifters.run_drifters()` with box-specific defaults and analysis functions:

- `run_small_box(t_start=5001, n_days=100, box_size_km=100, drifter_spacing_km=10, ...)` — calls `qg_drifters.run_drifters()` with box parameters.
- `compute_pair_separations(traj, dx, nx)` — for all pairs at each time, compute separation (periodic minimum-image). Returns a DataFrame: `(ID_i, ID_j, t, r_m)`.
- `compute_structure_functions(traj, nc_path, dx, nx)` — interpolate velocity to drifter positions, compute D_LL(r) and D_TT(r) binned by separation.
- Analysis defaults: `box_center_x=128.0`, `box_center_y=128.0`, `box_size_km=100`, `drifter_spacing_km=10`, `n_days=100`.

## R6: Backward compatibility

All changes to existing files must be backward compatible. The full-domain deployment (no box parameters) must produce identical results to the current code.

## R7: Metadata

The JSON metadata sidecar must include box parameters when they are used, so cached results can be distinguished from full-domain runs.
