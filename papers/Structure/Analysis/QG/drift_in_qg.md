## Context

We wish to modify Julia code to probe the outputs of a quasigeostrophic model. The model is a 2D model of the ocean, run for 20 years. The model output is saved in a NetCDF file. We will be using the MeshArrays and IndividualDisplacements (formerly Drifter) packages to load the model output and probe the outputs. These Julia packages are found here:
 - https://github.com/JuliaClimate/MeshArrays.jl
 - https://github.com/JuliaClimate/IndividualDisplacements.jl

## Here is how the activity should be organized

### QG output file

The QG output file is located at `$OS_DATA/QG/QGModelOutput20years.nc` (~23 GB). It was generated by [pyqg](https://pyqg.readthedocs.io/en/latest/index.html), a Python Quasigeostrophic Model.

**Grid:** 256 x 256 cells on a 1000 km x 1000 km doubly-periodic domain (grid spacing ~3.9 km).

**Layers:** 2 vertical levels (`lev` = 1, 2) with a layer interface at `lev_mid` = 1.5. Layer thickness ratio `delta` = 0.25 (upper layer is 1/4 of total depth).

**Time:** 7200 daily snapshots (~19.7 years). Model timestep `dt` = 3600 s (1 hour); output written every day.

**Variables:**
| Variable | Dimensions | Units | Description |
|----------|-----------|-------|-------------|
| `q` | (time, lev, y, x) | s^-1 | Potential vorticity in real space |
| `u` | (time, lev, y, x) | m s^-1 | Zonal velocity anomaly |
| `v` | (time, lev, y, x) | m s^-1 | Meridional velocity anomaly |

**Spectral coordinates:** `k` (129 zonal wavenumbers) and `l` (256 meridional wavenumbers) for Fourier-space analysis.

**Key physical parameters:**
- `beta` = 1.5e-11 m^-1 s^-1 (planetary vorticity gradient)
- `rd` = 15 km (Rossby deformation radius)
- `rek` = 5.787e-7 s^-1 (bottom friction)
- `del2` = 0.8 (Laplacian diffusion coefficient)
